# Sandcastles

Your content strategist for Instagram, TikTok, and YouTube Shorts.

Sandcastles helps short-form video creators research what's working across YouTube, TikTok, and Instagram. Discover top channels, analyze winning formats and hooks, recap watchlists, and turn insights into your next video.

This plugin connects Cursor and Grok Bot to the Sandcastles MCP server at https://mcp.sandcastles.ai/ and adds skills for researching formats, hooks, topics, channels, and top-performing videos. It requires a Sandcastles account.
